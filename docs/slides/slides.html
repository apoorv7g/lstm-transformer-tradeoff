Research Questions + Null Hypothesis

The question in testable form: given identical frozen CNN frame features, does a Transformer temporal head beat an LSTM head, and what does it cost on a CPU?

IDNull hypothesisHow it is tested
H0-acc
primary		Transformer AUROC = LSTM AUROC on short clips (T ≤ 40) with frozen MobileNetV2 featuresCorrected resampled t-test on paired folds; TOST equivalence, margin 0.03 AUROC
H0-cpuAt matched parameters, Transformer batch-1 CPU latency ≤ LSTM latencyMedian of ≥300 timed calls, 3 sessions, bootstrap CI on ratio
H0-TSequence length T (10, 20, 40) does not change AUROC for either familySame paired tests across T, Holm correction
Why this null: Soeleman et al. 2022 (LSTM ≥ Transformer on 3 small video sets, same feature design); Barros et al. 2021 (CNN + LSTM, 185 ultrasound videos, ~93%); the Keras video Transformer example "works best with a larger dataset". Literature check: 6 of 10 papers verified, 2 partly, 2 need DOIs.

Why cache the features?
Backbone frozen + no augmentation means identical outputs. MobileNetV2 runs once (~35k frames, ~10 to 20 min on CPU) instead of every epoch of every fold.
Fairness control
Every model reads the same feature file and the same split file. Only the temporal block differs, so differences come from that block alone.

Based on the Keras video Transformer example, with changes:
  • Projection to d: in the example 4.2 M of 4.23 M params sit in attention.
  • Pre-LN instead of post-LN: more stable on small data.
  • Mean pooling instead of max; no CLS token to learn.
  • transformer_base is parameter-matched to lstm_base (1.40 M vs 1.78 M).
Recipe: AdamW 3e-4, weight decay 1e-2, 5-epoch warm-up, dropout 0.1; same loss, batch, epoch budget and early stopping as the LSTM.

Benchmarking + Evaluation Protocol
Accuracy
  • AUROC (primary), macro-F1, balanced accuracy
  • Sensitivity (Abnormal recall), specificity, AUPRC
  • Stratified 5-fold x up to 3 seeds
  • Metrics only on held-out folds; out-of-fold predictions saved per video
  • Grid: 6 models x T {10, 20, 40} x 5 folds = 90 runs
Compute (CPU only)
  • Params; MACs (analytic + TF profiler)
  • Latency: 50 warm-up + ≥300 timed calls, median / p95
  • Batch 1 and 32; 1 and 8 threads; fresh process per model
  • Peak RAM (RSS), train s / epoch, model file size
  • Head-only and end-to-end with MobileNetV2
Machine: Intel Core i5-12450H (8 cores / 12 threads), 16 GB RAM, Windows 11, Python 3.11, TF 2.17, Keras 3.6
Statistics: corrected resampled t-test, 95% CI + Cohen's d, TOST (0.03 AUROC), McNemar + DeLong, Holm correction
